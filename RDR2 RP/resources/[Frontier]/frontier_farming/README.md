# Frontier Farming — foundation draft (not production ready)
Requires the accompanying Property, Inventory and Business changes. Start after those resources. SQL tables are created on startup. Build farm structures through existing Property camp menu. Stand nearby and use /farm to bind personally or to a company with a farm grant. Register a same-owner stock chest using Business and link it. This draft requires an administrator to supply registered farm tools, seeds, water and animal vouchers for testing; normal purchasing/filling is not implemented yet.

Implemented: field construction and pen configurations, persistent facility state, offline crop/animal progression, basic animal breeding and product collection, passive eggs, same-owner stock, journaled inventory mutations, local representative visuals, basic menu. Horse capacity definitions are reserved; horse gameplay disabled. No supplier, physical slaughter, timing minigame, real horse genetics/training/trade, licensed agricultural trade, water gathering, roaming AI, full terrain validation or recovery UI yet. Do not deploy to live server. The rules smoke test can be run from resource directory with lua5.4 tests/rules.lua. JavaScript syntax checked; Lua and database integration have not been executed. Existing Property previews do not yet update slope transforms live while moving; test only on flat ground. Derived small/large geometry needs validation. Company final liquidation currently removes farm state, not a detailed asset audit. Foreclosure and cross-resource lifecycle races require further work.
