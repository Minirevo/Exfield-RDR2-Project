# Frontier HUD and equipment foundation
Deploy the matching modified resources and ensure frontier_hud after frontier_economy and vorp_metabolism. Full restart required for patched VORP core/metabolism. No SQL migration: existing inventory containers are reused; known old food item definitions are upgraded in place without modifying stacks. HUD replaces VORP core and metabolism overlays when active. VORP still owns hunger/thirst persistence, decay, and death behavior; native minimap and core UI remain available. /frontierhud toggles the replacement. Cash and bank use Frontier economy minor units, refreshed every five seconds; health and native endurance/dead-eye cores sampled locally; unknown values display a dash. Native core semantics must be tested. No new survival simulation or money source.
Inventory: four private persistent equipment slots, long gun, sidearm, and two compatible ammo stacks (30 rounds each). Move items by drag/drop or context menu and back via satchel; weapon instance UUID is its serial. This is storage only; permanent native equip, loaded ammo persistence, and server-authoritative reload are not enabled yet. Gun Lab remains unchanged, separate from these items. No automatic migration of VORP weapons. Do not use test mode on production players.
Food wheel and inventory use bread, apple, water and cooked_meat; server inventory receipt commits first, then sends nutrition effects through existing metabolism API. Current bridge is not crash-atomic with VORP's client-side status save; animations and container returns are future work. Existing bandage/tonic behavior unchanged. Test using admin ACE /frontier_inv_test weapon_lancaster 1, weapon_cattleman 1, ammo_revolver 30, ammo_repeater 30, bread 3, water 3, apple 3, cooked_meat 3. Test equipment slot restrictions, partial stack transfer, serial after storage transfer/restart, food from both wheel and inventory, stale wheel revision rejection, HUD visibility and balances after transaction, VORP fallback after /frontierhud. Full native firearm migration is a separate follow-up.
