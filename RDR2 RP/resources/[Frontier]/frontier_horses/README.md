# Frontier Horses V1
Public stables use the seven VORP coordinates but not VORP runtime APIs. Run 001_horses.sql after Logistics 001; optional 002_import_legacy_optional.sql imports mapped legacy characters and preserves old numeric horse IDs and draft assignments. Back up old tables; disable vorp_stables and start frontier_horses after farming and before logistics. Full server restart required. No wipe. Existing ranch horses remain in their enclosure records until released. Release adult horse from farm with a purchased saddle in satchel, which moves the original certificate, genes, age and training atomically to the stable registry and equips it. If native spawning fails, the horse is stored at the nearest public stable. Horses no longer have an hour timer once released. Board physically at any stable; paid remote transfer between stables; disconnect/restart returns horse to its last stable. NPC horses have modest genes and no saddle. Tack shop buys saddle, saddlebags, brush and stirrups in cash; fit in stable. Bags open near active mount via /horsebags, /horsecall within 100m. Stable care and treatment services. Logistics draft candidates and assignment validation now use Frontier records; only previously validated Shire model. Existing company ranch horses remain company property. New draft teams must share wagon ownership. 
Limitations: no live RedM testing; native saddle component display, mount stats and spawn replication require verification. Training approximates movement near owner, not confirmed rider state. Public boarding has no recurring fees; no offline neglect for boarded horses. Public stables now sell player-ranch listings directly using a separate durable farm sale journal; buyer cash transfers to seller bank. Existing ranch-to-ranch market continues. Active Frontier horses can be returned to same-owner authorized livestock enclosures; the certificate and gear move atomically, and saddlebag contents remain with the certificate. Imported legacy breeds cannot be introduced to breeding until mapped. NPC purchases can use an authorized company account. Public stable resale of independently boarded horses is not implemented yet. Legacy import cannot infer original genes, breed sex or equipment accurately; assigns conservative values and basic saddle. Legacy VORP horses with no Core mapping are reported and remain in backup. Do not run VORP Stables simultaneously. 

The farm public-sale journal is created automatically by Farming at startup. Ranch-return buttons require a compatible enclosure, and the horse must physically accompany the player. The existing equipment visuals for saddle and saddlebags use bundled VORP asset hashes (no VORP runtime dependency); other tack visual variants need further testing.

Foals mature while boarded. /horsecare consumes one hay when near your active horse; a fitted brush improves care and stirrups slightly improve training. Ranch riding now requires Frontier Horses rather than the old checkout fallback. The Logistics manifest depends on frontier_horses, not vorp_stables.

## Startup recovery (1.1)
Horse initialization retries every five seconds instead of permanently failing when inventory or farming is not yet ready. The player sees the current initialization stage; the server console prints the detailed cause on change. Run `stabledebug` in the server console to inspect ready/busy/stage/error. Check that 001_horses.sql has run, including its ALTER TABLE; update and restart inventory if registration is forbidden. Farming creates ff_public_horse_sales on startup. Optional business and ranch market listing failures no longer prevent opening the stable. No additional SQL migration. Full restart recommended when updating inventory dependencies.

## Live market showroom
The Horse market tab shows one offer at a time with Previous/Next (or arrow keys), rotation controls, a live client-only horse model, coat/pattern labels, and a stat card. Seven preview positions and cameras come from the bundled VORP stable config; no VORP runtime dependency. NPC stock now uses the exact advertised baseline genetics instead of a hidden random roll; ranch listings retain their individual genetics and actual model. Existing horses are unchanged. Foals use the adult breed model for preview. Preview entities are not networked, not owned horses, and are removed when switching tabs, leaving the stable, closing the menu, or stopping the resource. No SQL migration. Restart farming and horses. Verify camera framing, model loading and cleanup at each stable in RedM; native runtime not tested here.
